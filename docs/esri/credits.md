# Crediting maps and software

Maps and figures made with ArcGIS credit the software, the basemap and each data source, as with any analytic tool. This page describes common practice for authors.

## Software

Name the product, and the version where there is one, in the methods section. For example:

> Maps were produced in ArcGIS Online (Esri, Redlands, CA).

> Analyses were performed in ArcGIS Pro version <span class="fill">[version]</span> (Esri, Redlands, CA).

## Basemaps and Living Atlas layers

ArcGIS basemaps and Living Atlas layers have their own attribution, shown in the corner of each web map. Keep that attribution visible in screenshots and exported figures.

## Data sources

Cite the original data steward and the date or version of each layer used in analysis, in addition to the service that hosted it. A layer from the Living Atlas that republishes census boundaries, for example, is cited to the Census Bureau with its vintage.

## Figure captions

A short form for captions:

> Map: <span class="fill">[author or organization]</span>, built with ArcGIS. Data: <span class="fill">[sources and dates]</span>.

## Maps from GeoALS tools

When a figure reproduces a GeoALS map or app, name the tool and the date it was viewed, and link to it. The tools are listed on [GeoALS maps and apps](../maps/tools.md).
