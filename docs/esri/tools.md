## Products GeoALS uses

| Product | What it is for | GeoALS example |
|---|---|---|
| [ArcGIS Online](https://www.esri.com/en-us/arcgis/products/arcgis-online/overview) | Cloud mapping: hosted layers, web maps, sharing and analysis | The hosted clinic database and every web map |
| [ArcGIS Hub](https://www.esri.com/en-us/arcgis/products/arcgis-hub/overview) | A public site that organizes maps, data and stories around an initiative | The ALS Geospatial Hub |
| [ArcGIS Experience Builder](https://www.esri.com/en-us/arcgis/products/arcgis-experience-builder/overview) | Web apps assembled from maps, lists, filters and text without code | Advisor Locator, Legislative Viewer |
| [ArcGIS Dashboards](https://www.esri.com/en-us/arcgis/products/arcgis-dashboards/overview) | Live charts, counts and maps on one screen | Clinic review summaries |
| [ArcGIS Survey123](https://www.esri.com/en-us/arcgis/products/arcgis-survey123/overview) | Form-based data collection that writes to a hosted layer | The Ed Mytych Advisor Survey and the add-a-clinic form |
| [ArcGIS StoryMaps](https://www.esri.com/en-us/arcgis/products/arcgis-storymaps/overview) | Narrative pages that combine text, maps and media | Patterns of Care in the U.S. |
| [ArcGIS Living Atlas of the World](https://livingatlas.arcgis.com/) | Curated ready-to-use layers, including census and federal data | Boundaries, demographics and context layers |
| [ArcGIS Location Platform](https://www.esri.com/en-us/arcgis/products/arcgis-location-platform/overview) | Location services for developers: basemaps, geocoding, routing | Named on the GeoALS site as the platform under the Hub |

## Products for analysis and development

| Product | What it is for |
|---|---|
| [ArcGIS Pro](https://www.esri.com/en-us/arcgis/products/arcgis-pro/overview) | Desktop GIS for advanced analysis, cartography and data management |
| [ArcGIS Instant Apps](https://www.esri.com/en-us/arcgis/products/arcgis-instant-apps/overview) | Quick single-purpose apps from a web map |
| [ArcGIS Field Maps](https://www.esri.com/en-us/arcgis/products/arcgis-field-maps/overview) | Mobile data collection and map viewing |
| [ArcGIS Notebooks](https://www.esri.com/en-us/arcgis/products/arcgis-notebooks/overview) | Python notebooks that run beside hosted data |
| [ArcGIS Maps SDK for JavaScript](https://developers.arcgis.com/javascript/latest/) | Custom web mapping applications, as used in the ALS Trial Navigator |
| [ArcGIS API for Python](https://developers.arcgis.com/python/) | Scripting and analysis against ArcGIS from Python |
| [R-ArcGIS Bridge](https://r.esri.com/) | Reading and writing ArcGIS data from R |

## Learn ArcGIS StoryMaps

Start with Esri's overview, explore an ALS example, then build a short story using a guided lesson.

| Resource | What you will learn |
|---|---|
| [ArcGIS StoryMaps overview](https://www.esri.com/en-us/arcgis/products/arcgis-storymaps/overview) | What StoryMaps does and how maps, text and media fit together |
| [ArcGIS StoryMaps Fundamentals](https://www.esri.com/en-us/training/catalog/5e14de4036e7e15d09b53af9/arcgis-storymaps-fundamentals) | Esri's free learning plan for developing storytelling skills |
| [Get started with ArcGIS StoryMaps](https://learn.arcgis.com/en/projects/get-started-with-arcgis-storymaps/) | A guided exercise using supplied maps, text and media to build a story |
| [Getting started with accessible storytelling](https://storymaps.arcgis.com/stories/02670c9018f14cfbbaef7cba5c54d453) | Ways to make stories usable by a broader audience |
| [StoryMaps resource center](https://www.esri.com/en-us/arcgis/products/arcgis-storymaps/resources) | Planning guidance, videos, tutorials and further training options |

For ALS examples, explore [Patterns of Care in the U.S. and The Advocate](../maps/storymaps.md). These illustrate how a narrative can explain care access or advocacy alongside maps.

Check the access requirements listed with each lesson. The guided *Get started* exercise currently requires a User, Publisher or Administrator role in an ArcGIS organization. A free learning resource does not necessarily include software access.

## Training with GeoALS

GeoALS experts can provide training tailored to a research team, clinic, community organization or advocacy group. Topics include GIS fundamentals, **ArcGIS StoryMaps**, maps and dashboards, environmental data linkage, data standards and location privacy.

Training can be a workshop, a short course or a component of a larger research project. See [Training with GeoALS](../grants/training.md) for topics, formats and an example project scope, or include it in a [grant or partnership proposal](../grants/index.md#ways-to-include-geoals).
